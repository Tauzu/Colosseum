# Colosseum

多人数参加型オンラインブラウザ生存ゲーム。

## コンセプト

ルームを作った瞬間から敵が増え続ける。一人では限界が来る。助けを呼ぶか、呼ばれて駆けつけるか。

```
[孤独な戦い] → [限界] → [ヘルプ] → [助っ人来る] → [形勢逆転] → [また増える] → ...
```

## 特徴

- **ヘルプ招集**: ゲーム中にヘルプを叫ぶと、ホーム画面のルーム一覧に赤フラグが立つ
- **助っ人ボーナス**: 遅れて参加するほど強い状態でスポーン（HP+50% / ATK+50%）
- **指数増殖 × 人数連動**: 助っ人が来ると15秒後に敵の増殖が加速する
- **ボス討伐クリア**: 8分後にボスが出現。倒したらルームクリア

## 技術スタック

- フロントエンド: HTML5 Canvas（ゲームエンジン不使用）
- リアルタイム通信: WebSocket（Socket.io）
- サーバー: Node.js
- DB: Redis
